メモQR転送 セットアップ手順

メモQR転送ツール セットアップ手順書

Visual Studio 2022 / WinForms / C# / .NET Framework 4.8。ZIPは使わず、ブラウザでGitHubを開いてコピーし、このページのコードを貼り付けて作ります。

0. 前提

  • NuGet・DLLは使いません。 QR生成ライブラリは、GitHubのソース（.csファイル41個）をプロジェクトに直接コピーして使います。
  • 対象フレームワークは .NET Framework 4.8 です。 .NET Framework 4.8 には System.Text.Json が含まれないため、JSONは手書きの文字列処理で作ります（NuGetを使わないため）。
  • このページの「コピー」ボタンでコードをコピーできます。全文を掲載しており、省略はありません。

1. プロジェクトを作成する

  1. Visual Studio 2022 を起動し、「新しいプロジェクトの作成」を選ぶ。
  2. テンプレートで 「Windows フォーム アプリ (.NET Framework)」（C#）を選ぶ。「.NET」（.NET 8 など）のテンプレートは選ばない。
  3. プロジェクト名を MemoQrTransfer にする。
  4. フレームワークが .NET Framework 4.8 になっていることを確認して作成する。

2. 不要なファイルを削除し、フォルダを作る

  1. ソリューションエクスプローラーで Form1.cs を右クリックして削除する。Form1.Designer.cs も同様に削除する（片方だけ残すとエラーになります）。確認が出たら「OK」。
  2. プロジェクト名（MemoQrTransfer）を右クリック →「追加」→「新しいフォルダー」で、次の3つを作る。
    • Models
    • Services
    • Library

3. プロジェクトファイル（csproj）に LangVersion を追加する

.NET Framework のプロジェクトは、既定の C# 言語バージョンが古いため、ライブラリのソースがコンパイルエラーになることがあります。ソリューションエクスプローラーで MemoQrTransfer.csproj をダブルクリックして開き、最初の <PropertyGroup> の中に次の1行を追加して保存します（既に LangVersion がある場合は、その値を latest に変えてください）。

MemoQrTransfer.csproj（追加する行）
  <PropertyGroup>
    ...（既存の行はそのまま残す）...
    <LangVersion>latest</LangVersion>
  </PropertyGroup>

4. Program.cs を置き換える

ソリューションエクスプローラーの Program.cs を開き、中身をすべて次の内容に置き換えます。

5-1. MainForm.cs（画面と操作）

MainForm.cs
using System;
using System.Drawing;
using System.Windows.Forms;
using MemoQrTransfer.Models;
using MemoQrTransfer.Services;

namespace MemoQrTransfer
{
    /// <summary>単一フォーム。UIはコードで組み立てる（デザイナーファイル不要）。</summary>
    public class MainForm : Form
    {
        // --- UI ---
        private TextBox _memoBox;
        private Button _btnGenerate;
        private Button _btnNew;
        private Label _lblInfo;
        private PictureBox _picture;
        private Button _btnPrev;
        private NumericUpDown _numPart;
        private Label _lblTotal;
        private Button _btnNext;
        private Button _btnPlay;
        private Button _btnStop;
        private CheckBox _chkLoop;
        private CheckBox _chkAuto;
        private Label _lblIntervalCaption;
        private NumericUpDown _numInterval;

        // --- 状態 ---
        private QrDocument _doc;
        private int _currentIndex;       // 0 始まり
        private bool _updatingPartNumber; // NumericUpDown を内部から変更中のフラグ
        // System.Threading.Timer と衝突しないよう完全修飾名で指定
        private readonly System.Windows.Forms.Timer _timer = new System.Windows.Forms.Timer();

        public MainForm()
        {
            BuildUi();

            _timer.Tick += Timer_Tick;
            _timer.Interval = (int)_numInterval.Value;

            UpdateInfo();
            UpdateControls();
        }

        // ==================== UI 構築 ====================

        private void BuildUi()
        {
            Text = "メモQR転送ツール";
            StartPosition = FormStartPosition.CenterScreen;
            FormBorderStyle = FormBorderStyle.FixedSingle;
            MaximizeBox = false;
            ClientSize = new Size(1010, 760);
            Font = new Font("Yu Gothic UI", 9F);

            // メモ入力
            var lblMemo = new Label { Text = "メモ", Location = new Point(12, 12), AutoSize = true };
            _memoBox = new TextBox
            {
                Location = new Point(12, 34),
                Size = new Size(360, 300),
                Multiline = true,
                ScrollBars = ScrollBars.Vertical,
                AcceptsReturn = true
            };

            _btnGenerate = new Button { Text = "QR生成", Location = new Point(12, 345), Size = new Size(110, 36) };
            _btnGenerate.Click += BtnGenerate_Click;

            _btnNew = new Button { Text = "新規", Location = new Point(132, 345), Size = new Size(110, 36) };
            _btnNew.Click += BtnNew_Click;

            _lblInfo = new Label
            {
                Location = new Point(12, 395),
                Size = new Size(360, 90),
                AutoSize = false
            };

            // QR表示
            _picture = new PictureBox
            {
                Location = new Point(390, 12),
                Size = new Size(600, 600),
                SizeMode = PictureBoxSizeMode.Zoom,
                BorderStyle = BorderStyle.FixedSingle,
                BackColor = Color.White
            };

            // ページ移動
            _btnPrev = new Button { Text = "前へ", Location = new Point(390, 625), Size = new Size(90, 32) };
            _btnPrev.Click += (s, e) => ShowPart(_currentIndex - 1);

            var lblPart = new Label { Text = "Part", Location = new Point(490, 633), AutoSize = true };
            _numPart = new NumericUpDown
            {
                Location = new Point(530, 628),
                Size = new Size(80, 25),
                Minimum = 1,
                Maximum = 1,
                Value = 1
            };
            _numPart.ValueChanged += NumPart_ValueChanged;

            _lblTotal = new Label { Text = "/ 0", Location = new Point(618, 633), AutoSize = true };

            _btnNext = new Button { Text = "次へ", Location = new Point(680, 625), Size = new Size(90, 32) };
            _btnNext.Click += (s, e) => ShowPart(_currentIndex + 1);

            // 自動再生
            _btnPlay = new Button { Text = "再生", Location = new Point(390, 675), Size = new Size(90, 32) };
            _btnPlay.Click += (s, e) => StartPlayback();

            _btnStop = new Button { Text = "停止", Location = new Point(490, 675), Size = new Size(90, 32) };
            _btnStop.Click += (s, e) => StopPlayback();

            _chkLoop = new CheckBox { Text = "ループ", Location = new Point(600, 680), AutoSize = true, Checked = true };

            _chkAuto = new CheckBox { Text = "自動再生", Location = new Point(690, 680), AutoSize = true, Checked = false };

            _lblIntervalCaption = new Label { Text = "間隔(ms)", Location = new Point(390, 722), AutoSize = true };
            _numInterval = new NumericUpDown
            {
                Location = new Point(470, 718),
                Size = new Size(100, 25),
                Minimum = 100,
                Maximum = 60000,
                Increment = 100,
                Value = 1500
            };
            _numInterval.ValueChanged += (s, e) => _timer.Interval = (int)_numInterval.Value;

            Controls.AddRange(new Control[]
            {
                lblMemo, _memoBox, _btnGenerate, _btnNew, _lblInfo,
                _picture,
                _btnPrev, lblPart, _numPart, _lblTotal, _btnNext,
                _btnPlay, _btnStop, _chkLoop, _chkAuto,
                _lblIntervalCaption, _numInterval
            });

            FormClosing += (s, e) =>
            {
                _timer.Stop();
                _picture.Image = null;
                _doc?.Dispose();
            };
        }

        // ==================== 生成 ====================

        private void BtnGenerate_Click(object sender, EventArgs e)
        {
            string memo = _memoBox.Text;
            if (string.IsNullOrEmpty(memo))
            {
                MessageBox.Show(this, "メモを入力してください。", "確認", MessageBoxButtons.OK, MessageBoxIcon.Information);
                return;
            }

            // 生成は押下時のみ。前回のBitmapは破棄してから作り直す
            StopPlayback();

            var newDoc = new QrDocument { Id = DateTime.Now.ToString("yyyyMMddHHmmss") };

            try
            {
                var split = MemoSplitter.Split(memo, newDoc.Id);

                Cursor = Cursors.WaitCursor;
                foreach (var json in split.Jsons)
                {
                    newDoc.Parts.Add(new QrPart
                    {
                        PartNo = newDoc.Parts.Count + 1,
                        TotalParts = split.Jsons.Count,
                        Json = json,
                        Image = QrBitmapFactory.Create(json)
                    });
                }
            }
            catch (Exception ex)
            {
                newDoc.Dispose();
                Cursor = Cursors.Default;
                MessageBox.Show(this, "QR生成に失敗しました。\r\n" + ex.Message, "エラー", MessageBoxButtons.OK, MessageBoxIcon.Error);
                return;
            }
            finally
            {
                Cursor = Cursors.Default;
            }

            // 古いデータを画面から外してから破棄
            _picture.Image = null;
            _doc?.Dispose();
            _doc = newDoc;

            _updatingPartNumber = true;
            _numPart.Maximum = _doc.Count;
            _numPart.Value = 1;
            _updatingPartNumber = false;
            _lblTotal.Text = "/ " + _doc.Count;

            ShowPart(0);

            if (_chkAuto.Checked)
            {
                StartPlayback();
            }
        }

        // ==================== 表示・ページ移動 ====================

        private void ShowPart(int index)
        {
            if (_doc == null || _doc.Count == 0) return;

            if (index < 0) index = 0;
            if (index > _doc.Count - 1) index = _doc.Count - 1;

            _currentIndex = index;
            _picture.Image = _doc.Parts[index].Image; // Bitmap は保持済み。ここでは再生成しない

            _updatingPartNumber = true;
            _numPart.Value = index + 1;
            _updatingPartNumber = false;

            UpdateInfo();
            UpdateControls();
        }

        private void NumPart_ValueChanged(object sender, EventArgs e)
        {
            if (_updatingPartNumber) return;
            ShowPart((int)_numPart.Value - 1);
        }

        // ==================== 自動再生 ====================

        private void StartPlayback()
        {
            if (_doc == null || _doc.Count == 0) return;
            _timer.Interval = (int)_numInterval.Value;
            _timer.Start();
            UpdateControls();
        }

        private void StopPlayback()
        {
            _timer.Stop();
            UpdateControls();
        }

        private void Timer_Tick(object sender, EventArgs e)
        {
            if (_doc == null || _doc.Count == 0)
            {
                StopPlayback();
                return;
            }

            if (_currentIndex < _doc.Count - 1)
            {
                ShowPart(_currentIndex + 1);
            }
            else if (_chkLoop.Checked)
            {
                ShowPart(0); // 最後のPartから先頭へ戻る
            }
            else
            {
                StopPlayback(); // ループOFFなら最後で停止
            }
        }

        // ==================== 新規（リセット） ====================

        private void BtnNew_Click(object sender, EventArgs e)
        {
            if (_doc == null && _memoBox.Text.Length == 0) return;

            var result = MessageBox.Show(this, "現在のQRを破棄しますか？", "確認",
                MessageBoxButtons.YesNo, MessageBoxIcon.Question);
            if (result != DialogResult.Yes) return;

            _timer.Stop();                 // Timer停止
            _picture.Image = null;         // PictureBoxクリア（先に外してから破棄する）
            _doc?.Dispose();               // Bitmap破棄
            _doc = null;                   // QR一覧クリア
            _memoBox.Clear();              // メモ入力クリア
            _currentIndex = 0;             // 現在Part初期化

            _updatingPartNumber = true;
            _numPart.Maximum = 1;
            _numPart.Value = 1;
            _updatingPartNumber = false;
            _lblTotal.Text = "/ 0";

            UpdateInfo();
            UpdateControls();
        }

        // ==================== 表示更新 ====================

        private void UpdateInfo()
        {
            int chars = _memoBox.Text.Length;
            int count = _doc?.Count ?? 0;
            string part = count == 0 ? "-" : (_currentIndex + 1).ToString();

            _lblInfo.Text =
                "文字数: " + chars + "\r\n" +
                "QR数: " + count + "\r\n" +
                "Part: " + part + " / " + count;
        }

        private void UpdateControls()
        {
            bool hasDoc = _doc != null && _doc.Count > 0;
            bool playing = _timer.Enabled;

            _btnPrev.Enabled = hasDoc && _currentIndex > 0 && !playing;
            _btnNext.Enabled = hasDoc && _currentIndex < _doc.Count - 1 && !playing;
            _numPart.Enabled = hasDoc && !playing;
            _btnPlay.Enabled = hasDoc && !playing;
            _btnStop.Enabled = playing;
        }
    }
}

using System;
using System.Collections.Generic;

namespace MemoQrTransfer.Models
{
    /// <summary>生成されたQR群全体。Bitmapの破棄もここで行う。</summary>
    public class QrDocument : IDisposable
    {
        public string Id { get; set; }
        public List<QrPart> Parts { get; } = new List<QrPart>();

        public int Count => Parts.Count;

        public void Dispose()
        {
            foreach (var part in Parts)
            {
                part.Image?.Dispose();
                part.Image = null;
            }
            Parts.Clear();
        }
    }

5-4. Services/MemoSplitter.cs

Services/MemoSplitter.cs
using System;
using System.Collections.Generic;
using System.Text;

namespace MemoQrTransfer.Services
{
    /// <summary>
    /// メモ本文をパートに分割する。
    /// 1パート約700文字を目安にし、JSON化後のUTF-8バイト数が上限を超える場合は
    /// 分割文字数を減らして作り直す。
    /// </summary>
    public static class MemoSplitter
    {
        public const int DefaultChunkChars = 700;
        public const int MinChunkChars = 50;
        public const int MaxJsonBytes = 2200; // ECC=M・バイトモードの上限(2331)に余裕を持たせた値

        /// <summary>分割結果（各パートのJSON）。</summary>
        public class Result
        {
            public List<string> Jsons { get; } = new List<string>();
        }

        public static Result Split(string memo, string id)
        {
            int chunkChars = DefaultChunkChars;

            while (true)
            {
                var chunks = SplitText(memo, chunkChars);
                var result = new Result();
                bool tooLarge = false;

                for (int i = 0; i < chunks.Count; i++)
                {
                    string json = QrJsonBuilder.Create(id, i + 1, chunks.Count, chunks[i]);
                    if (Encoding.UTF8.GetByteCount(json) > MaxJsonBytes)
                    {
                        tooLarge = true;
                        break;
                    }
                    result.Jsons.Add(json);
                }

                if (!tooLarge)
                {
                    return result;
                }

                // 上限を超えたパートがあれば分割文字数を減らして再分割
                chunkChars -= 50;
                if (chunkChars < MinChunkChars)
                {
                    throw new InvalidOperationException("分割後のデータがQRコードに収まりません。");
                }
            }
        }

        /// <summary>文字数で分割する。サロゲートペア（絵文字など）の途中では切らない。</summary>
        private static List<string> SplitText(string text, int chunkChars)
        {
            var chunks = new List<string>();
            int pos = 0;

            while (pos < text.Length)
            {
                int end = Math.Min(pos + chunkChars, text.Length);

                // 直前の文字がサロゲートペアの上位なら、1文字手前で切る
                if (end < text.Length && char.IsHighSurrogate(text[end - 1]))
                {
                    end--;
                }

                chunks.Add(text.Substring(pos, end - pos));
                pos = end;
            }

            return chunks;
        }
    }
}

5-5. Services/QrJsonBuilder.cs

Services/QrJsonBuilder.cs
using System.Text;

namespace MemoQrTransfer.Services
{
    /// <summary>1パート分のJSONを作る（System.Text.Json を使わない版）。</summary>
    /// <remarks>
    /// 出力形式：{"id":"...","part":1,"total":3,"text":"..."}
    /// 日本語などの非ASCII文字はそのまま出力する（\uXXXX にしない）。
    /// JSONで必須のエスケープ（" \ 制御文字）だけを行う。
    /// </remarks>
    public static class QrJsonBuilder
    {
        public static string Create(string id, int part, int total, string text)
        {
            var sb = new StringBuilder();
            sb.Append("{\"id\":\"").Append(Escape(id))
              .Append("\",\"part\":").Append(part)
              .Append(",\"total\":").Append(total)
              .Append(",\"text\":\"").Append(Escape(text))
              .Append("\"}");
            return sb.ToString();
        }

        private static string Escape(string s)
        {
            if (string.IsNullOrEmpty(s)) return string.Empty;

            var sb = new StringBuilder(s.Length + 16);
            foreach (char c in s)
            {
                switch (c)
                {
                    case '"':  sb.Append("\\\""); break;
                    case '\\': sb.Append("\\\\"); break;
                    case '\b': sb.Append("\\b");  break;
                    case '\f': sb.Append("\\f");  break;
                    case '\n': sb.Append("\\n");  break;
                    case '\r': sb.Append("\\r");  break;
                    case '\t': sb.Append("\\t");  break;
                    default:
                        if (c < 0x20)
                        {
                            sb.Append("\\u").Append(((int)c).ToString("x4"));
                        }
                        else
                        {
                            sb.Append(c);
                        }
                        break;
                }
            }
            return sb.ToString();
        }
    }
}

5-6. Services/QrBitmapFactory.cs

Services/QrBitmapFactory.cs
using System.Drawing;
using System.IO;
using Net.Codecrete.QrCodeGenerator;

namespace MemoQrTransfer.Services
{
    /// <summary>JSON文字列から QR コードの Bitmap を作る（Nayuki 由来ライブラリを使用）。</summary>
    public static class QrBitmapFactory
    {
        private const int QuietZone = 4;      // 余白（モジュール数）
        private const int DisplaySize = 600;  // PictureBox の目安サイズ(px)

        public static Bitmap Create(string json)
        {
            // ECC = M 固定 / バージョン自動選択 / UTF-8 を ECI で明示 / ECC の自動引き上げなし
            var qr = QrCode.EncodeTextAdvanced(
                json,
                QrCode.Ecc.Medium,
                boostEcl: false,
                minVersion: QrCode.MinVersion,
                maxVersion: QrCode.MaxVersion,
                eci: ECI.UTF8);

            int modules = qr.Size + QuietZone * 2;
            int scale = System.Math.Max(1, DisplaySize / modules);

            byte[] png = qr.ToPngBitmap(QuietZone, scale);

            // Image.FromStream は元ストリームを使い続けるため、コピーして独立させる
            using (var ms = new MemoryStream(png))
            using (var img = Image.FromStream(ms))
            {
                return new Bitmap(img);
            }
        }
    }
}

7. ビルドと実行

  1. 「ビルド」→「ソリューションのビルド」（Ctrl+Shift+B）。エラー一覧が0件であることを確認する。
  2. F5 で実行する。

エラーが出た場合は、エラー一覧の先頭のメッセージ（例：「型または名前空間 'QrCode' が見つからない」）を控えておくと原因を特定しやすくなります。多くの場合、Library のファイル名の抜けや、コピーの不完全が原因です。

8. 動作確認

  1. 「メモ」欄に700文字を超える日本語の文章を入力する。
  2. 「QR生成」を押す。「QR数」と「Part: 1 / n」が表示され、QRコードが表示されること。
  3. 「前へ」「次へ」、Part番号の欄で切り替えられること。
  4. 「再生」で自動切替され、「停止」で止まること。「ループ」ONなら最後のPartの後に先頭へ戻ること。
  5. スマホのカメラでQRを読み取り、JSON（id / part / total / text）と日本語が正しく読めること。
  6. 「新規」で確認ダイアログが出て、メモ・QR・Part表示がクリアされること。

9. 仕様との対応

ECC = M 固定QrBitmapFactory.Create：QrCode.Ecc.Medium、boostEcl: false

10. よくあるつまずき

  • 「C# 言語バージョン 7.3 ではサポートされていません」などのエラー：csproj の LangVersion を latest にする（3節）。
  • 「Form1 が既に定義されている」などのエラー：Form1.Designer.cs が残っていないか確認する（2節）。
  • 「Timer があいまい」エラー：MainForm.cs の _timer の型が System.Windows.Forms.Timer になっているか確認する。
  • 「型 'QrCode' が見つからない」など：Library フォルダのファイルが41個そろっているか、ファイル名が GitHub と一致しているか確認する。
  • 日本語が正しく表示されない：フォント「Yu Gothic UI」を使っています。Windows 10 以降なら標準で入っています。
  • QRが読めない：表示が小さすぎる可能性があります。PictureBox の大きさは 600×600 程度です。
  • 容量超過の例外：MemoSplitter.MaxJsonBytes を下げてください（2200 → 2000 など）。
  • ライブラリを更新したい：GitHub の該当タグ（今回は v3.2.1）の QrCodeGenerator フォルダから、同じ手順で差し替えてください。
